Ligar o login no sistema

O painel grava os acessos na chave users do banco estoque (IndexedDB) — o mesmo que o index.html já usa. Para o sistema passar a pedir usuário e senha, cole este trecho no index.html, logo abaixo da função kvGet:

/* acessos criados no admin.html */
function acessos(){return kvGet('users').then(function(u){return Array.isArray(u)?u:[]})}
acessos().then(function(us){
  if(!us.length)return;                    /* ainda sem acessos: sistema livre */
  var s=JSON.parse(sessionStorage.getItem('ses')||'null');if(!s){location.replace('admin.html');return}
  var u=us.filter(function(x){return x.user===s.user&&x.ativo})[0];
  if(!u){location.replace('admin.html');return}
  if(u.validade&&new Date(u.validade+'T23:59:59')<new Date()){location.replace('admin.html?exp=1');return}
  document.documentElement.dataset.acesso=JSON.stringify({nome:u.nome,perfil:u.perfil,perms:u.perms,extras:u.extras});
});

Depois disso, o menu do sistema pode ser montado a partir de dataset.acesso (ex.: esconder Produtos de quem não tem a permissão).
